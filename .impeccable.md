## Design Context

### Users

DevWisp serves people who use a browser or Android device to continue their own Codex and Claude Code work remotely. They need to move quickly between conversations, files, terminals, and configuration, including on narrow mobile screens.

### Brand Personality

Practical, clear, and calm. The interface should feel like a capable development tool, with visible state and straightforward controls.

### Aesthetic Direction

Keep the project's selectable visual themes. For settings, use the user's Claude Code reference as the layout direction: a grouped navigation column beside a focused content area, with restrained surfaces and a readable line length. Do not stretch the settings form across the full available width.

### Design Principles

1. Make the current location and next action obvious without repeated headings or unnecessary panels.
2. Keep controls readable and reachable on desktop and mobile, adapting navigation to narrow space.
3. Preserve state and user input when moving between settings sections.
4. Follow each selected theme's contrast, icon style, and focus treatment.
