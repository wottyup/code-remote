# 网页排队图片发送后草稿重现修复

## 目标与分类

带图片的消息进入排队后，切换并发窗口再返回时，输入框不再重新出现已排队的图片。属于修复 / PATCH，纠正现有图片草稿清理时机，不改变排队发送能力。目标版本 `0.103.10-dev.1`。

## 实施步骤

1. 梳理输入框图片在发送、排队、切换聊天及失败恢复时的存储顺序。
2. 对已有聊天，在提交请求前就持久化清空图片草稿；成功后不再执行一次延迟清空，避免覆盖随后新加的图片。新建聊天继续保留已有的跨会话图片转移流程。
3. 让图片草稿写入后通知当前挂载的输入框，确保异步发送失败恢复的图片也能在切回聊天后显示。
4. 更新版本及简要版本历史，构建网页并检查差异；仅本地提交，不推送远端。不新增或运行测试。

## 验收要点

- 已有聊天的带图消息进入排队后，切走再切回，图片只出现在排队项中，不回到输入框。
- 发送失败时原图片回到输入框草稿；新建聊天的图片转移不受影响。
- 提交后新添加的图片不会被旧请求完成时的清理操作删除。
