# 设置页侧边导航改版

## 需求与版本

用户希望设置页参考 Claude Code 的设置界面：左侧按类别导航，右侧只显示当前设置项，不再逐项上下折叠；右侧内容保留适合阅读的宽度。当前所有设置能力、主题配色和保存行为继续可用。归类为体验优化（PATCH），目标版本 `0.97.5-dev.1`。

## 开发步骤

1. 将设置页的八个模块整理为分组导航，记录上次访问的模块，并在切换后让内容滚动回顶部。
2. 将各模块的折叠容器改为固定显示的设置区块；切换模块时保留未保存的表单状态，快捷键录制离开模块时取消。
3. 建立居中的双栏布局，左侧导航独立滚动，右侧内容限制最大宽度；窄屏改为横向可滚动导航。
4. 沿用现有各主题的颜色、边框和图标风格，明确标示当前模块，并保留键盘焦点状态。
5. 更新版本和简短版本历史，构建网页、检查差异，仅在本地提交本次改动。

## 验收要点

- 点击导航后，右侧只显示相应设置，且没有上下折叠按钮。
- 桌面版内容不会横向铺满设置页；手机仍能找到全部导航项和设置控件。
- 主题、显示、翻译、CPA、MCP、快捷键、通知与关于均可访问，设置操作保持有效。
