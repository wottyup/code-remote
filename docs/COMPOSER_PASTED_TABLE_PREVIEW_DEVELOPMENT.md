# 输入框粘贴表格预览

## 需求与版本

用户将电子表格或 Markdown 表格粘贴到聊天输入框时，希望直接看到表格，并在窄屏中左右滑动查看列。现有流程只在输入框显示 Markdown 原文，长表格只显示文档文件名。新增可视化预览属于新增功能（MINOR），目标版本 `0.98.0-dev.1`。

## 开发步骤

1. 扩展粘贴识别：保留现有 HTML、制表符表格转换，识别完整的 Markdown 表格文本；普通文字维持原有粘贴规则。
2. 将识别出的表格保存为待发送 Markdown 文档，输入框内展示真实的表格预览；文档数量达到上限时退回现有的正文插入方式，避免丢失粘贴内容。
3. 预览支持水平与垂直滚动、窄屏触摸滑动、表头、行列数量及移除。保留编辑原文入口，编辑后仍发送实际 Markdown 内容。
4. 将待发送表格草稿按聊天保存到当前浏览器，切换聊天或刷新后恢复；发送成功和删除聊天时清理。预览限制一次渲染的行数，明确提示未预览的行仍会完整发送；沿用现有主题颜色和输入框布局。
5. 更新版本记录和版本号，完成网页构建与差异检查，仅在本地提交；不推送远端。

## 验收要点

- 粘贴 HTML 表格、TSV 或纯 Markdown 表格后，输入框显示表格而非大段 Markdown；多列表格可左右滑动。
- 表格文本可编辑和移除；发送、排队、修改排队消息时内容一致。
- 普通文字、图片及其他文档粘贴仍按现有流程处理；超出附件数量时表格内容仍保留。
- 未发送表格在刷新和切换聊天后仍属于原聊天，排队消息编辑不覆盖原草稿。

## 完成记录

- HTML、制表符和完整的 Markdown 表格粘贴会进入表格附件，输入区与发送后的消息均显示可横向滑动的表格。表格原文可在输入区编辑或移除。
- 表格区域同时支持纵向滚动；单列固定可读宽度，长路径在单元格中换行。输入区最多预览 200 行，历史消息最多预览 60 行，并限制约 2000 个单元格；未预览内容仍完整发送。
- 附件已满时改为插入正文，避免丢失粘贴数据。版本更新为 `0.98.0-dev.1`，只交付网页端，不生成 Android 安装包。
- 未发送的表格附件按聊天保存在浏览器，切换聊天和刷新后恢复；编辑排队消息时保留原草稿，删除聊天时清理。超过 2 MB 的表格草稿仍可发送，但浏览器会提示无法保存以供刷新后恢复。
- TypeScript 编译和 Vite 网页构建通过，差异检查通过；未新增或运行测试。
