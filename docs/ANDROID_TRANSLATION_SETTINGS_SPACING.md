# Android 聊天翻译设置间距调整

## 问题与分类

聊天翻译设置顶部同时显示多段重复说明、刷新结果和模型清单，选项之间也缺少分组间距，手机上阅读拥挤。此次属于体验优化 / PATCH：整理现有设置的说明和间距，现有翻译操作不变。Android 目标版本 `0.106.3-dev.1`，`versionCode 423`。本次局部版式调整不单独写入 CHANGELOG。

## 实施步骤

1. 精简顶部说明，显示当前配置来源和读取状态，继续展示加载错误；使用的模型仍在配置选项中可见。
2. 给翻译行为与引擎配置两组选项留出间距，增大每行的最小点击区域，沿用现有主题、字体和设置样式。
3. 补齐新增界面文案的英文翻译，保持窄屏、字体缩放与多连接场景可用。
4. 编译独立版本 APK，手机可连接时覆盖安装并检查实际界面、配置选择与刷新状态。
5. 记录验证结果，保留旧安装包，仅将本次修改提交至本地 Git。

## 验收关注点

- 顶部信息简洁，当前电脑来源清楚，加载或刷新失败仍可见。
- 翻译开关、显示译文、英文表达、引擎、配置选择和刷新入口均可操作。
- 内容分组清楚，长文字可换行，英文界面和已选主题正常显示。
