# Android 聊天表格横向滚动修复

## 需求与分类

聊天中的 Markdown 表格在窄屏上会裁掉右侧列，手指在表格上左右滑动也无法查看。现有表格已有横向容器和逐格选字能力，本次修复其宽度测量与触摸交接，属于修复 / PATCH。

目标版本 `0.103.4-dev.1`，Android `versionCode 409`。新安装包单独保存。

## 实施步骤

1. 核对原生表格宽度、可选择文字的触摸行为，以及聊天页左右侧栏手势的优先级。
2. 让表格实际布局宽度覆盖全部列；在横向拖动时由表格滚动，纵向拖动交还聊天页，长按仍可选择单元格文字。
3. 更新版本号与简短版本记录，编译 Android APK，核对包内版本与改动。
4. 设备可连接时覆盖安装并检查表格手势；保存独立 APK，本地提交，不推送 GitHub。
