# 网页侧边栏回复中标题呼吸提示

## 目标与分类

左侧聊天列表中，正在回复的标题显示与输入框同节奏的呼吸提示；切换聊天或并发窗口后仍能看到对应聊天的状态。属于体验优化 / PATCH，增强现有回复状态的可见性，不改变操作方式。目标版本 `0.103.9-dev.1`。

## 实施步骤

1. 复用现有的聊天运行状态判断：已打开的聊天优先读取所属窗口的实时回复状态，其他聊天读取列表中的运行状态；开始与结束事件及时同步列表状态。
2. 仅在回复中的标题上增加柔和的背景呼吸效果，共用输入框现有动画节奏；保持文字清晰，并为减少动态效果偏好的用户保留静态提示。
3. 更新版本及简要版本历史，构建网页并检查差异；仅本地提交，不推送远端。不新增或运行测试。

## 验收要点

- Codex 和 Claude 聊天在回复期间，左侧对应标题有呼吸提示，回复结束后停止。
- 同时打开多个聊天时，每个标题独立反映自己的状态；切走聊天后状态仍正确。
- 各主题下标题可读，减少动态效果设置下没有持续动画。
