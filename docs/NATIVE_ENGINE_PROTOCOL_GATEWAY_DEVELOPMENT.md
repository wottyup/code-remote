# 本机 CLI 接口协议转换

## 需求与分类

Codex、Claude API 配置的协议下拉应能选择 Responses、Anthropic Messages、Chat Completions，并真正使用所选协议进行测试和聊天。此前仅展示禁用项，不能完成用户期望的协议切换。

本次为新增功能（MINOR），版本 `0.103.0-dev.1`：新增跨协议调用能力。Android 仅同步版本名称，不生成安装包，`versionCode` 保持 `408`。

## 设计与边界

- 原生协议保持直接连接；跨协议时，由 Code Remote 的本机 HTTP 转换入口承接 CLI 请求，再使用配置中选择的协议连接上游。
- 每次应用跨协议配置生成独立的私有连接快照和随机凭据。CLI 只持有本机地址及该凭据；上游密钥仍由后端保存。保存备用配置不会改变已运行会话的接口和密钥。
- 同一个本机入口支持两种 CLI 原生请求格式，转换系统提示、对话、图片、工具定义、工具调用和工具结果。Codex 的命名空间及自定义文本工具适配为标准函数，并在回复中还原。
- 流式文字逐段转发；工具参数完整后才确认工具调用。上游错误、超时或断流不能被误报为正常完成。保持输出用量统计，禁止把密钥、完整上游错误或提示词写入日志。
- 只有本机回环请求并通过独立连接凭据验证才能访问转换入口；普通配对令牌不替代该凭据。限制请求和响应大小、连接超时及重定向。
- 无法跨协议表示的上游托管工具、加密思考内容及会话续接功能不伪造支持；工具执行仍由本机 CLI 完成。跨协议模式需要 Code Remote 后端保持运行，界面明确说明。
- Codex 默认附带的可选联网工具声明会在跨协议时省略；显式要求使用该工具、历史中的托管工具项目及其他无法转换的内容会返回错误。原生协议仍直接使用原有能力。
- Claude 的精确 Token 计数接口在跨协议时不提供估算值；无法使用该接口时返回明确的不支持错误。跨协议支持文本、图片及本机函数工具，不等同于完整复制上游所有专用扩展。
- 转换连接需要后端监听回环地址。旧快照保留，供已经运行的 CLI 会话继续使用；保存、删除备用配置及切换配置不会改写旧快照。

4. 检查工具往返、图片、流式成功/错误、配置切换和凭据隔离的实现；按当前开发约束，本次不新增或运行测试。
5. 完成生产构建及差异检查，同步版本历史并本地提交，不推送。服务生效处理须保留其他运行任务和终端。

## 验收要点

- 两种引擎均可保存并重新读取任意协议，切换时保留本配置的密钥。
- 跨协议配置应用后，本机文件仍使用 CLI 原生协议，真实上游请求采用用户选择的协议。
- 普通文字、图片和一次函数调用后的工具结果可以在三种格式之间转换。
- 流式请求在上游完成前可见文字；未完成或中途出错的工具调用不会被正常完成。
- 已保存配置、当前应用配置和 CLI 本机网关地址不会相互混淆；更新备用配置不改变现有连接。
- 未认证、非回环、路径错误、无效协议及超限请求被拒绝；浏览器及日志不接收已有上游密钥。

## 历史图片导致文字模型无法续聊（2026-11-04）

### 问题与分类

用户配置的 `mercury-3` 为纯文字模型。设置连通性检查只有文字，能够通过；CLI 恢复含图片的历史对话时，会再次提交历史图片，上游可能拒绝整个请求。

本次按修复（PATCH）处理，版本 `0.103.2-dev.1`：修复已有跨协议聊天在历史包含图片时无法继续发送文字的问题，不新增图片识别能力。

### 实施顺序

1. 在请求解码时记录完整原始用户消息的边界，区分历史图片与本轮附件；工具结果不单独视为新用户轮次。
2. 仅当上游明确表示不支持图片时，对历史图片使用文字占位说明重试；保留历史原文件、文字、工具调用及工具结果。本轮仍有图片时返回明确提示，不静默省略。
3. 成功省略历史图片后，在首次实际文字回复中加入提示；同一轮工具往返不重复加入。按连接和模型记住明确的图片能力拒绝，限制缓存数量，减少重复失败请求。
4. 仅在明确不支持参数名时重试旧版 Chat Token 参数，防止图片错误引起无效的参数重试。上游错误只用于内部分类，不输出原文或凭据。
5. 同步版本和更新概述，完成生产构建、Python 编译与差异检查；不新增或运行测试，随后本地提交，不推送。检查现有服务结构后处理生效，不能中断同一服务中的其他项目任务。

### 检查要点

- 原始用户消息内的图片、文字顺序不影响本轮附件判定；工具结果里的图片同样遵循轮次边界。
- 不支持图片的明确拒绝与图片格式、下载失败、工具和普通参数错误分别处理。
- 流式文字与最终回复包含相同提示，工具调用和原有错误清理流程保持有效。
- 不修改保存的对话，也不把模型名称硬编码为不支持图片；有图片能力的模型仍正常接收图片。

- 图片能力拒绝缓存按私有连接和实际模型隔离，最多 128 项、5 分钟过期；普通 400 错误不会触发图片省略，Chat 旧参数重试也需要明确的参数拒绝。
