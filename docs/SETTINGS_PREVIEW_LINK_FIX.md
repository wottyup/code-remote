# 设置入口可作为右侧预览链接

## 目标与分类

设置页已经有可直接打开的 `/settings` 路由，但侧栏入口是只执行程序导航的按钮。将该入口改为带真实地址的链接，使浏览器扩展的自定义 URL 前缀规则能在点击时识别目标。普通点击仍打开应用内设置面板，浏览器历史行为保持一致。

本次修正已有设置入口的操作便利性，属于修复（PATCH），继续使用目标版本 `0.100.0` 的内部测试阶段，版本递增到 `0.100.0-dev.3`。

## 实施步骤

1. 给设置入口提供真实的 `/settings` 链接；普通左键点击沿用现有面板处理，修饰键与中键保留浏览器原生链接行为。
2. 确保链接继续使用现有侧栏按钮样式，不出现下划线或布局变化。
3. 更新 Web 与 Android 版本、简要版本记录；不修改扩展里的站点规则。
4. 从 pnpm workspace 根目录构建网页，检查产物和预览服务响应，再检查 Git 差异并本地提交，不推送。

## 验收

- 点击“设置”仍打开应用内面板，地址栏为 `/settings`；刷新和浏览器前进后退保持可用。
- 配置匹配 `/settings` 的扩展 URL 前缀后，点击设置入口可由扩展打开右侧预览。
- 在没有扩展接管时，修饰键或中键可将设置页作为独立链接打开。
