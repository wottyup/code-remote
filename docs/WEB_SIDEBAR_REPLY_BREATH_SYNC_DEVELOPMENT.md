# 网页侧边栏回复呼吸节奏同步

## 目标与分类

多个聊天同时回复时，左侧聊天项应同亮同暗；后来开始回复的聊天应加入当前节奏。属于修复 / PATCH，纠正已有状态提示互相错开的表现，不增加新操作。目标版本 `0.103.12-dev.3`。

## 实施步骤

1. 保留现有整行呼吸样式和 5.5 秒节奏，让回复中的聊天项按页面统一时钟设置动画相位。
2. 在聊天项进入回复状态时设置一次相位，持续回复期间不重设；停止回复后重新开始时再同步。避免持续计时器和逐帧更新。
3. 更新版本及简要版本历史，构建网页并检查差异；仅本地提交，不推送远端。不新增或运行测试。

## 验收要点

- 同时回复的聊天项同步变亮、变暗；后开始回复的聊天项不会从头单独闪烁。
- 切换聊天、列表重排或重新进入回复状态后仍使用统一节奏。
- 减少动态效果设置下仍保持静态提示。
