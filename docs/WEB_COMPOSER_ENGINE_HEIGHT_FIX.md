# 网页 Codex 与 Claude 输入框默认高度统一

## 目标与分类

两个模式的文字输入区域使用相同默认高度，避免切换模式时输入框忽高忽低；用户手动拖动设置的高度继续保留。属于修复 / PATCH，改进现有布局。目标版本 `0.103.7-dev.1`。

## 实施步骤

1. 移除 Claude 单独的较矮默认高度，统一初始高度、切换模式和布局变化时的默认值。
2. 保留紧凑横屏高度与各模式已手动调整的高度逻辑。
3. 更新版本及简短版本记录，构建网页并检查差异；仅本地提交，不推送远端。不新增或运行测试。

## 验收要点

- Codex 与 Claude 在相同窗口宽度、没有附件和队列时使用相同默认文字输入高度。
- 排队消息仍在文字区域上方自然扩展，用户手动拖动后的高度不被默认值覆盖。
