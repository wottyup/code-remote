# Android 消息信息与翻译配置修复

## 需求与版本

修正安装界面图标比例、排队消息发送瞬间误显示在聊天区、翻译配置刷新不符合网页版选择的情况，并在 AI 回复下方显示实际模型与思考等级。模型和等级此前无法在 App 回复中查看，按新增功能（MINOR）归类；目标版本 `0.106.0-dev.1`、`versionCode 420`。

## 实施步骤

1. 检查自适应图标前景图与安装界面预览，缩小图形在图标画布中的占比，保留现有品牌图形。
2. 核对网页消息的模型、思考等级数据来源及 Android 消息结构，只在有真实元数据的已完成 AI 回复下方显示对应值。
3. 区分立即发送和进入排队的乐观展示；预计排队的消息不先插入聊天区，提交结果回来后由排队列表显示。保留立即发送的即时反馈与失败恢复。
4. 核对翻译配置接口、网页版选择保存位置与 App 刷新流程。修复可直接读取的配置刷新；对于只存在浏览器本地的选择，提供清楚、可操作的选择和状态提示。
5. 检查差异，编译并打包 Android，核对新 APK 并保留旧版本；更新版本记录、本地提交。未经用户要求不推送 GitHub。

## 验收关注点

- 安装界面的品牌图形有明显留白，不贴满图标区域。
- AI 回复完成后，显示该回复实际模型和思考等级；缺少元数据时不猜测。
- 排队消息不再先闪入聊天区再消失。
- 手机能看到电脑端已保存的翻译配置，刷新失败可见原因；浏览器本地选择与电脑端模型配置的关系清楚。

## 实施与验证

- 已缩小自适应图标前景、按网页字段读取每条 AI 回复的真实模型与思考等级、修正预计排队消息的乐观显示，并让翻译配置选择列出所有可用引擎与模型。
- 用电脑端现有配置确认接口会公开 Responses、Chat Completions 与 Anthropic 三套已配置模型；密钥没有输出或复制到手机。
- `:app:compileDebugKotlin` 与 `:app:assembleDebug` 通过；`git diff --check` 通过。当前 ADB 没有连接设备，因此安装界面的最终效果及手机交互尚未真机验收。
