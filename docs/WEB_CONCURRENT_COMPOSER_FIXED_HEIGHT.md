# 并发窗口输入框固定外框与队列布局

## 目标与分类

并发窗口切换时，输入框外框默认保持“有一行折叠排队消息”时的高度。没有排队消息的窗口让文字输入区填满上方空间，提示文字靠顶部；有排队消息时，队列占据顶部，文字区下移，底部操作栏保持原位。属于修复 / PATCH，修正现有布局行为。目标版本 `0.103.8-dev.1`。

## 实施步骤

1. 在并发模式为队列和文字区建立同一高度的布局容器，以折叠队列和现有文字区作为不可交互的尺寸基准。
2. 无队列时让文字区填满该容器；有队列时让队列在上方自然占位。展开队列、附件、翻译预览和手动调整输入高度时允许外框按内容增长。
3. 保持 Codex 与 Claude 默认文字区高度一致，更新版本和简短版本记录；构建网页、检查差异并仅本地提交。不新增或运行测试，不推送远端。

## 验收要点

- 并发窗口在空队列与折叠队列之间切换时，输入框外框及底部按钮位置稳定。
- 空队列时提示文字靠输入框顶部；有队列时提示文字位于队列下方。
- 单窗口布局沿用现有自然高度，展开队列和特殊内容不会被固定高度裁剪。
