# 网页侧边栏回复中整行呼吸提示

## 目标与分类

正在回复的聊天应由左侧聊天项整行显示呼吸提示，包含图标、标题和时间所在区域；当前选中的聊天也应可见。属于体验优化 / PATCH，修正现有状态提示的覆盖范围，不增加新操作。目标版本 `0.103.12-dev.1`。

## 实施步骤

1. 将呼吸背景层从标题文字移至聊天项整行，继续复用输入框的动画节奏；图标和文字置于背景层上方。
2. 调整选中聊天项的伪元素规则，让回复中的选中项同样显示呼吸效果；保留减少动态效果时的静态提示。
3. 更新版本与简要版本历史，构建网页并检查差异；仅本地提交，不推送远端。不新增或运行测试。

## 验收要点

- Codex 和 Claude 聊天在回复期间，左侧对应聊天项整行呼吸，回复结束后停止。
- 当前选中的聊天与未选中的聊天均能显示；图标、标题和时间保持清晰。
- 各主题沿用原有聊天项配色；减少动态效果设置下无持续动画。
