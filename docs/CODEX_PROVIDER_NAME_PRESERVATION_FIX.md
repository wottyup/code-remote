# 保留 Codex 提供方名称

## 目标

修复（PATCH），版本 `0.107.1-dev.1`。网页应用 Codex API 配置时保留现有 `model_provider`，避免旧对话因提供方名称变化而无法继续。

## 实施步骤

1. 读取并更新当前提供方的地址及 Bearer Key，保留提供方名称、其他提供方与无关配置。未声明提供方时使用 Codex 默认的 `openai`，不新增根级名称覆盖。
2. 保持现有模型选择及协议网关能力；新建提供方表时补齐 Responses 协议和认证设置，已有表只改地址及 Key。
3. 覆盖原名称、留空密钥、默认提供方、旧托管配置块及复杂 TOML 安全校验，更新版本并本地提交。

## 限制

已被旧版本改成 `code_remote_settings` 的文件没有可靠记录原名，因此不猜测恢复名称；用户恢复正确名称后，后续应用配置将保留该名称。
