# 网页排队消息默认收起

## 目标与分类

排队消息出现或新增时，默认保持收起；用户仍可点击标题手动展开。属于体验优化 / PATCH，调整现有队列的展示方式，不增加新操作。目标版本 `0.103.11-dev.1`。

## 实施步骤

1. 移除消息提交中及定时消息入队后强制展开排队栏的逻辑。
2. 保留手动展开、手动收起及队列清空后恢复收起的现有行为。
3. 更新版本和简要版本历史，构建网页并检查差异；仅本地提交，不推送远端。不新增或运行测试。

## 验收要点

- 普通消息和定时消息进入队列后，排队栏默认只显示折叠标题。
- 用户点击标题后仍能查看、编辑和调整排队消息。
- 队列清空再出现时仍默认收起。
