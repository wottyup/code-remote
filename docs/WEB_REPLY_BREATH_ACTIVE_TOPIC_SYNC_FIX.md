# 网页当前话题呼吸同步修复

## 目标与分类

当前话题正在回复时，左侧对应聊天项应与输入框同时变亮、变暗。补充一份可直接打开的 HTML 演示页，方便查看切换话题和错时开始回复时的表现。属于修复 / PATCH，纠正现有状态提示的同步问题；演示页只用于查看效果，不改变聊天操作。目标版本 `0.103.12-dev.5`。

## 实施步骤

1. 将两处呼吸层改为可直接读取动画的元素，保持原有外观；等待动画可用后，以当前输入框的动画相位校准左侧聊天项，输入框本身不被校准。
2. 输入框未呼吸时，让正在回复的聊天项彼此保持同步；切换话题、动画重新开始时再次校准。
3. 在 `public/sidebar-breath-sync.html` 放置独立演示页，包含错时开始回复和切换当前话题的操作。
4. 更新版本和简要版本历史，构建网页并检查差异；仅本地提交，不推送远端。不新增或运行测试。

## 验收要点

- 当前话题的侧边栏聊天项与输入框同步呼吸，输入框动画未被重新启动。
- 后开始回复的聊天项能接入当前节奏，切换话题后重新对齐。
- 演示页可通过现有网页端口独立打开；减少动态效果时没有持续动画。
