# 网页并发输入框空队列留白修复

## 目标与分类

并发窗口没有排队消息时，输入文字从输入框正常顶部位置开始；出现排队消息时，由实际队列区域自然将文字下推。属于修复 / PATCH，调整现有输入框布局，不增加新操作。目标版本 `0.103.6-dev.1`。

## 实施步骤

1. 移除并发窗口空队列的隐藏占位元素及其透传参数，保留实际排队消息模块。
2. 删除仅服务于该占位元素的样式，保持各主题下真实队列的显示与输入框高度设置。
3. 更新版本和简短版本记录，构建网页并检查差异；仅本地提交，不推送远端。不新增或运行测试。

## 验收要点

- 无排队消息时，输入框顶部不再留出一行看不见的队列区域。
- 有排队消息时，队列仍位于文字输入区域上方；并发窗口可分别按自身队列状态显示。
