# 网页 AI 回复模型与思考副标题

## 目标与版本

在网页每条完成的 AI 回复底部显示该轮实际使用的模型和思考等级，使用低对比度副标题样式，不改变回复正文、流式显示、翻译和复制操作。Codex 与 Claude Code 都要支持；历史消息与当前流式消息沿用同一条元数据路径。该功能属于新增可见能力，目标版本为 `0.99.0-dev.1`。

## 实施步骤

1. 为消息和回合增加可选的模型、思考等级字段；Codex 历史读取 `turn_context`，Claude Code 回合保存启动参数，旧记录没有字段时保持兼容。
2. 将回合元数据从历史快照、`turn/started`、发送确认和本地流式消息合并到助手消息，确保排队消息、切换模型、刷新页面和多窗口不会把当前选择误显示到旧回复。
3. 在助手消息内容和操作记录之后添加副标题，显示模型名称与思考等级；回复生成中不显示，完成后才显示，沿用现有主题、字体大小和移动端字间距。
4. 更新版本记录和版本号，执行网页构建与差异检查；不新增或运行自动化测试，不重启服务，不推送远端。

## 验收要点

- Codex 和 Claude Code 完成回复的底部都能看到“模型”和“思考”副标题。
- 连续切换模型或思考等级后，每条回复显示自己的实际配置，不被下一条消息覆盖。
- 刷新或重新打开历史对话时，已有元数据继续显示；旧消息没有元数据时页面仍正常显示。
- 流式回复、翻译显示、选择题、操作记录和复制按钮布局不被破坏。
- TypeScript 编译、Vite 网页构建和差异检查通过；只创建本地提交，不推送远程。

## 后续修复

紧凑历史读取使用 SQLite 投影时不会保留 `turn_context`，因此补充按 rollout 修订版本缓存的轻量 JSONL 元数据扫描，把模型和思考等级合并回投影中的回合；没有元数据的旧记录仍保持兼容。
