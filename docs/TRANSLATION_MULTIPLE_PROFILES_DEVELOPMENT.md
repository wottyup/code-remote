# 翻译配置支持多套保存与切换

## 需求与版本

新增功能（MINOR），目标版本 `0.96.0-dev.1`。每种翻译引擎可保存多套具名配置，在设置页新建、复制、重命名、删除和切换；切换后输入预览、发送前翻译、排队消息编辑、选择题回复及 AI 回复译文均使用选中的配置。

## 开发步骤

1. 将服务端翻译配置扩展为按引擎保存的具名配置列表。读取旧版单配置文件时迁移为各引擎的“默认配置”，保留原有密钥与字段；写入保持原子替换和仅所有者可读权限。配置列表只公开密钥是否存在，绝不回传密钥。
2. 增加创建、复制、更新、删除配置的接口；禁止删除某引擎最后一套配置。连通性检查指定配置，未填写的新密钥沿用该套已保存密钥。翻译接口接受可选配置 ID；旧客户端未传 ID 时继续使用默认配置。
3. 设置页提供配置选择、名称和管理按钮。当前浏览器分别记住每种引擎选用的配置；无效或已删除的配置需明确提示，不得静默把消息发往另一套接口。
4. 所有网页翻译请求传入所选配置 ID；预览与回复缓存键包含配置 ID，切换时重新取得对应译文，避免沿用另一套配置的结果。
5. 更新版本与简短更新记录，完成静态检查和网页构建，仅提交本次文件到本地仓库。后端按现有空闲重启流程加载更新，确认运行版本。

## 边界

配置本身由服务器共享，当前选用哪套由每个浏览器分别保存。删除某套配置后，其他仍选用它的浏览器会收到明确错误，需要在设置页重新选择；服务端不会自动改用别的密钥或接口。
