# 设置页覆盖整个工作区

## 目标与分类

进入设置页时覆盖聊天列表、聊天内容和右侧文件树，让设置成为独立的工作区页面；设置页内部的分类导航和关闭按钮继续保留，关闭后恢复原来的聊天状态。Token 用量页沿用相同的全工作区层级，避免两个全局面板出现不同的遮挡规则。

本次属于体验优化（PATCH）：设置能力不变，只调整页面层级和可视范围。目标版本为 `0.100.0-dev.4`，Android `versionCode` 递增到 `408`。

## 实施步骤

1. 为设置和 Token 用量面板所在的工作区增加全局面板状态类。
2. 将全局面板定位到工作区最上层，覆盖左右侧栏与聊天区域，并保留主题、移动端和安全区样式。
3. 更新版本记录，执行网页生产构建和差异检查，完成本地 Git 提交，不推送远程。

## 验收要点

- 打开 `/settings` 时左侧聊天列表和右侧文件树不可见、不可操作。
- 设置内部导航、滚动和关闭按钮正常工作。
- `/usage-stats` 与设置页使用一致的覆盖范围。
- 关闭面板后原聊天布局和侧栏状态恢复。

## 实施结果

- 已让两个全局面板覆盖整个工作区，保留设置内部导航和原有历史路由行为。
- `pnpm --filter code-remote build` 与 `git diff --check` 已通过；未生成 Android 安装包，未运行自动化测试，未推送远程。
