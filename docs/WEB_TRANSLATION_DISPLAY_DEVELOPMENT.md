# 网页聊天原文与译文显示切换

## 需求与版本

新增显示模式选择（MINOR），目标版本 `0.94.0-dev.1`。翻译发送与聊天显示分别控制：翻译开启时，中文草稿仍译成英文发给 AI；聊天默认显示未翻译原文。用户在设置页的翻译模块开启“显示译文”后，自己的消息以实际发送的英文为主，AI 回复以中文译文为主。显示模式切换不修改已发送内容。

## 开发步骤

1. 在翻译设置中增加独立的“显示译文”开关，默认关闭；保留原翻译开关控制是否翻译发送。浏览器保存显示偏好，关闭显示译文时不为 AI 回复发起译文请求。
2. 发送中文消息时，连同实际英文提示记录中文原文；普通发送、排队、定时发送与排队编辑都保留对应关系。AI 实际接收的仍是英文，重开聊天和换设备后也能恢复原文。
3. 用户消息按显示偏好切换中文原文与英文发送稿，并提供另一版本的查看入口。AI 回复在显示译文时使用中文为主、英文可展开；关闭时直接显示英文原文。工具记录与可点击选择题保持可用。
4. 更新版本与简短版本记录，完成构建和静态检查，仅本地提交本次文件。后端改动在当前对话结束后安全重启。

## 边界

旧聊天如果此前没有保存中文原文，只能显示实际发送的英文；不会凭译文反推用户原句。翻译失败时继续保留草稿，不把未经翻译的中文误发给 AI。
