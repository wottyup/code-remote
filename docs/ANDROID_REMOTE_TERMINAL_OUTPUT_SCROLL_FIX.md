# Android 远端终端操作日志滚动修复

## 需求与分类

AI 接管终端后，聊天操作记录中的长终端输出被限制在固定高度内，但手指在输出区域上下滑动时由外层聊天页面接收，无法浏览输出全文。修复已有查看能力的操作问题，归类为修复 / PATCH。

目标版本 `0.97.4-dev.1`，Android `versionCode 400`。新安装包保留独立文件。

## 实施步骤

1. 核对终端输出框与聊天页面的滚动容器及现有内层滚动手势实现。
2. 让终端输出框在可滚动方向接管手势；到达内容边界后把手势交还给聊天页面。
3. 更新版本与简短版本记录；编译 Android 包，检查改动并保存新包。
4. 如设备可连接，安装新包；完成后本地提交，不推送 GitHub。
