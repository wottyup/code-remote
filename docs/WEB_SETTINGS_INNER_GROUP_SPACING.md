# 网页设置内部选项层级与间距

## 需求与版本

体验优化（PATCH），目标版本 `0.97.3-dev.3`。设置页各主模块可以折叠，但展开后选项之间主要靠细线区分，翻译配置里的开关、表达方式和接口表单也连成一片。用户难以快速找到具体设置。调整视觉层级和间距，不改变配置含义及保存行为。根据后续反馈，翻译引擎选择属于接口配置，英文表达属于翻译方式，两者应分别归类。

## 开发步骤

1. 为设置页内部选项建立统一的浅色底、可见边框、留白和标题层级；覆盖主题自定义、显示、快捷键、通知、CPA 接入和 MCP 授权等内容。
2. 将翻译设置按翻译行为、翻译方式和接口配置分成有标题的小区块；英文表达放在方式区，引擎选择放在接口配置区并紧邻所选配置。增加表单字段与操作按钮之间的距离。
3. 调整主题选项卡和背景图片取景区域，让可选项边界更清晰；为移动端保留足够宽度，避免横向溢出。
4. 检查浅色、暖色、复古、像素和自定义主题的内部区块对比度；更新版本与简短版本历史。
5. 执行网页构建与差异检查，仅暂存本次文件并创建本地提交。

## 验收要点

- 展开各设置模块后，选项标题、说明和控件能快速区分，连续选项之间有明显间隔。
- 翻译开关位于行为区，英文表达位于方式区；翻译引擎与所选配置位于接口配置区。
- 窄屏没有横向滚动或控件被卡片遮挡；折叠、保存和即时预览逻辑保持可用。
