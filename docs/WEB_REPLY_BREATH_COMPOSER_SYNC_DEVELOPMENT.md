# 网页回复呼吸提示统一节奏

## 目标与分类

正在回复时，输入框保持原有呼吸节奏，左侧所有回复中的聊天项跟随输入框当前相位；输入框没有呼吸时，聊天项之间仍保持同步。属于修复 / PATCH，纠正现有提示彼此错开的表现，不增加新操作。目标版本 `0.103.12-dev.4`。

## 实施步骤

1. 保留输入框原有动画，读取其当前动画相位，并将回复中的聊天项对齐到该相位。
2. 输入框没有动画时，以已有回复中的聊天项为基准同步其他聊天项；只在动画开始或元素挂载时校准，避免逐帧更新和持续计时器。
3. 保留各主题样式与减少动态效果设置，更新版本及简要版本历史，构建网页并检查差异；仅本地提交，不推送远端。不新增或运行测试。

## 验收要点

- 输入框原有节奏不变，回复中的左侧聊天项与其同步变亮、变暗。
- 多个并发聊天在不同时间开始回复时也接入当前节奏；输入框不呼吸时左侧聊天项仍同频。
- 回复结束后提示停止；减少动态效果时没有持续动画。
