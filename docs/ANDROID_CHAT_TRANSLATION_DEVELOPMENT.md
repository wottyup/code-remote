# Android 聊天翻译接入

## 需求与分类

Android 聊天复用网页已配置的电脑端翻译引擎和模型配置。用户可在 App 中输入中文、预览英文并将英文发给 AI，查看 AI 英文回复的中文译文及原文。此能力原生 App 尚未提供，归类为新增功能（MINOR），目标版本 `0.105.0-dev.1`，`versionCode 419`。

## 实施步骤

1. 沿用现有 `/api/v1/codex/translation/config`、`/api/v1/codex/translation` 和 `translated-inputs` 接口。配置、模型地址与密钥保存在电脑端；App 只保存开关、引擎、配置 ID 和表达风格，不复制或回显密钥。
2. 设置页增加聊天翻译分组。读取电脑端已有的引擎与配置供选择，标识未配置或已删除的项目；用户可设置启用翻译、是否优先显示译文和英文表达风格。切换电脑连接时刷新配置。
3. 输入框在中文草稿稳定后异步请求英文预览。普通发送、定时发送和编辑排队消息在提交前确认最新译文；翻译失败或草稿发生变化时保留原稿且不提交。请求体同时携带 `originalText`，供网页和 App 显示原文。
4. 读取已有翻译消息的原文记录。用户消息支持原文/实际发送文本切换；AI 完成回复后按需异步翻译并提供英文原文入口。控制翻译缓存和请求数量，避免在每次流式刷新时重译。
5. 更新版本记录与 Android 版本号，检查改动并本地提交。不主动打包、安装或推送 GitHub。

## 实施结果与验证

- 已接入电脑端配置读取、草稿预览、发送前翻译、排队与定时消息原文保留，以及 AI 回复完成后的按需译文。手机只保存引擎、配置 ID 和显示偏好。
- 翻译请求使用独立线程池，发送请求不会占用聊天同步线程；草稿、附件或连接变化时阻止旧译文提交。
- 已运行 `:app:compileDebugKotlin --offline --no-daemon` 与 `git diff --check`。本次未打包或真机验收。

## 验收关注点

- App 选择网页已配置的翻译引擎和配置后无需再次输入密钥；未配置或配置已删除时明确提示。
- 中文草稿翻译后只发送英文，排队和定时消息保留原文，英文输入直接发送。
- 翻译失败不清空输入框；回复翻译在整条完成后才请求，不影响聊天实时更新。
