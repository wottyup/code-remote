# 翻译设置下拉菜单主题对比度修复

## 诊断与版本

修复（PATCH），目标版本 `0.97.3-dev.4`。翻译设置的 `option` 被固定为白色背景和深色文字；黑色主题的全局文字规则优先级更高，把选项文字改为白色，导致展开菜单出现白字白底。原生下拉也未声明与主题一致的 `color-scheme`。

## 开发步骤

1. 给翻译设置的下拉控件和选项设置同一组主题颜色，并用足够明确的选择器覆盖全局黑白文字规则。
2. 为各内置主题配置下拉背景、文字和选中项的反色；自定义主题根据当前文字明暗设置原生控件色系，展开选项使用不透明的自定义底色。
3. 保留原生 `select` 的键盘和移动端行为；只修改翻译设置中的下拉菜单，不改其他页面的选择框。
4. 更新内部版本和简短版本历史，执行网页构建和差异检查，仅提交本次文件到本地仓库。

## 验收要点

- 黑色主题的展开选项有深色背景和浅色文字，不再出现白字白底。
- 浅色、暖色、复古、像素、中国复古及自定义主题的下拉与当前主题同色系，选中项保持清晰对比。
- 不改变已保存的翻译引擎、表达方式和配置内容。
