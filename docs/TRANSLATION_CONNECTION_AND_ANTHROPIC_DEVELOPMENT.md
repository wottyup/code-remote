# 翻译连通性检查与 Anthropic Messages 接口

## 需求与版本

新增功能（MINOR），目标版本 `0.95.0-dev.1`。翻译设置新增“测试连通性”，使用当前表单内容完成一次实际试译，不保存草稿；密钥留空时沿用服务器已保存的密钥。翻译引擎新增原生 Anthropic Messages 接口，可配置密钥、模型及可选接口地址。

## 开发步骤

1. 扩展后端引擎类型和配置读取，复用保存时的字段校验构造临时测试配置。测试请求不写入配置文件或翻译缓存，返回清晰的试译结果或不含密钥的错误。
2. 以 Anthropic Messages 格式发送翻译指令与待译文本，设置 `x-api-key`、`anthropic-version`、`max_tokens`，解析文本内容块及停止原因。默认接口地址指向 Anthropic 官方服务，并允许填写兼容原生协议的地址。
3. 前端增加引擎选项、相应字段和连通性按钮。按钮使用未保存草稿，防止重复提交；结果在当前设置模块显示。
4. 更新版本及简短更新记录。完成静态检查和网页构建，仅将本次文件提交到本地仓库。
5. 网页预览直接读取新构建；后端按现有空闲重启流程加载新接口，避免中断正在回复的对话。检查当前服务是否已加载目标版本。

## 边界

连通性检查会向所选引擎发出一次实际翻译请求，可能产生少量 API 用量。检查成功只代表当时的地址、凭据与模型可以处理该试译句，不保证后续长文本或服务状态不变。
