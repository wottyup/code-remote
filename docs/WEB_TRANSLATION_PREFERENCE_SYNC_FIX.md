# 网页翻译设置同步修复

## 目标与分类

修复（PATCH），目标版本 `0.104.6-dev.1`。网页翻译开关在设置页仍显示开启时，输入框曾没有英文发送预览，中文也直接发给 AI。翻译接口随后恢复请求并返回成功；故障的单一根因尚未证实。本次处理设置状态滞后这一可确认的风险，不修改翻译服务或用户配置。

## 开发步骤

1. 核对翻译偏好的读取、保存、输入预览及各发送入口，确认状态从设置页传递到聊天页的路径。
2. 设置变更时立即保存；页面重新获得焦点或其他标签页修改设置时同步状态。
3. 输入预览和发送入口读取当前可用的设置；浏览器存储不可用时沿用内存中的设置，避免误用默认关闭状态。
4. 执行网页构建，检查提交差异只包含网页修复、版本及本开发文档；只做本地提交。

## 验收与边界

- 开启翻译后，普通中文草稿显示英文预览，发送前按当前设置翻译；关闭后不触发翻译。
- 切换标签页或返回页面时，显示与实际发送采用一致的翻译设置。
- 翻译服务失败时维持已有的错误处理；本次不声称已定位先前的瞬时故障。
