# 译文模式下等待译文再显示回复

## 需求与版本

修复翻译显示顺序（PATCH），目标版本 `0.94.1-dev.1`。当用户启用聊天翻译并选择优先显示译文时，页面不能先展示英文回复，再跳成中文。模型仍把原文交给后端翻译接口；网页只在译文返回后显示该条回复的正文。翻译关闭或“显示译文”关闭时沿用原文实时显示。

## 开发步骤

1. 回复进行中只显示回复状态与工具活动，不展示尚未翻译的助手正文；原文保留在会话数据中供切换显示使用。
2. 普通回复完成后，向现有后端翻译接口发送这条正文一次；等待期间显示状态，返回后把译文作为正文。仍在进行中的选择题在问题内容完整时翻译，避免阻塞回答。相同正文复用缓存，绝不按 token 发起翻译。
3. 翻译失败时显示错误与重试入口，允许用户主动展开英文原文；复制按钮按当前实际显示内容工作。选择题及工具操作保持可用。
4. 更新版本记录，构建与静态检查，仅本地提交。

## 边界

当前会话数据仍会携带英文原文，以支持原文切换与历史恢复；本次修复的是用户可见的回复顺序。翻译服务故障时不自动把英文正文展示出来。
