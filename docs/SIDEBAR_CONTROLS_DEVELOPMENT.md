# 侧栏操作入口调整

## 范围与分类

- 将左侧栏底部的退出配对入口移至设置页，减少日常切换时误点。
- 为右侧文件树增加折叠整个右侧栏的入口，在聊天顶部保留展开按钮。用户已确认收起整个右侧栏。
- 分类为体验优化（PATCH），目标版本为 0.103.1-dev.1；不生成 Android 安装包。

## 步骤

1. 复用当前退出回调，在设置页导航底部提供退出配对入口，保留未保存 API 配置的离开提醒。
2. 接入右侧栏折叠状态，记住桌面的折叠偏好，保留文件树与上传状态；移动端继续使用现有的抽屉开关。
3. 完成前端构建和代码差异检查，不新增或运行测试，完成后本地提交。

## 生效

本次操作均在前端处理，构建后的网页刷新即可加载，无需为这次界面调整重启后端。

## 按钮位置修正（0.103.1-dev.2）

用户反馈展开和收起按钮坐标有偏差。原先两个入口分别属于聊天标题栏和文件树标题栏，会受标题栏高度、内边距和并发窗口按钮影响。本次属于修复（PATCH），只调整既有操作的位置，不新增使用能力。

1. 将桌面展开与收起入口合并为工作区右上角的同一个按钮，两个状态共用尺寸与定位。
2. 为文件树标题栏和收起时最右侧聊天标题栏预留按钮空间，避免遮住原有操作；手机继续使用抽屉按钮。
3. 保留折叠状态记忆和键盘焦点；执行前端生产构建、差异检查并本地提交。此次细节调整不单独追加版本历史条目，不生成 Android 安装包。

完成结果：桌面两种状态已共用工作区右上角同一个按钮，位置固定，切换时保留焦点；并发窗口下只为最右侧聊天标题栏预留空间。`pnpm --filter code-remote build` 和 `git diff --check` 已通过，刷新网页生效，无需重启。
